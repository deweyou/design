# Source Han CN Fonts

These files are extracted from the official Adobe Source Han simplified-Chinese releases.

Source Han Serif CN:

- Release: `2.003R`
- Package: `14_SourceHanSerifCN.zip`
- Source: `https://github.com/adobe-fonts/source-han-serif/releases/tag/2.003R`
- License: `SIL Open Font License 1.1`

Vendored serif weights for content and display typography:

- `SourceHanSerifCN-Regular.otf` for body text
- `SourceHanSerifCN-Medium.otf` for emphasis text
- `SourceHanSerifCN-SemiBold.otf` for title text
- `SourceHanSerifCN-Bold.otf` for strong emphasis

Source Han Sans SC:

- Release: `2.005R`
- Package: `09_SourceHanSansSC.zip`
- Source: `https://github.com/adobe-fonts/source-han-sans/releases/tag/2.005R`
- License: `SIL Open Font License 1.1`

Vendored sans weights for default UI and control typography:

- `SourceHanSansSC-ExtraLight.otf`
- `SourceHanSansSC-Light.otf`
- `SourceHanSansSC-Normal.otf`
- `SourceHanSansSC-Regular.otf`
- `SourceHanSansSC-Medium.otf`
- `SourceHanSansSC-Bold.otf`
- `SourceHanSansSC-Heavy.otf`

The package intentionally keeps `mono` content on the existing monospace stack.
